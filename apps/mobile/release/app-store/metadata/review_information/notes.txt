Manual SAMUR is an independent, unofficial reference guide to the public procedures manual of SAMUR-Protección Civil (Madrid's municipal emergency medical service). It is not affiliated with, sponsored or endorsed by SAMUR-Protección Civil or the Ayuntamiento de Madrid, and it uses no official logos or coats of arms. The first launch shows this disclaimer, and it is repeated in Settings (sliders button, top right of Inicio) and at the end of the App Store description.

No account and no login. There is nothing to sign in to; every feature is available right after the first-launch notice ("Entendido, abrir el manual").

Content: the procedures, drug reference (vademécum), radio codes and hospital/base directory are bundled inside the app, and the app downloads newer versions from our own public, read-only backend (https://manualsamur.miguelrzazo13.workers.dev). The content is reference material for trained emergency staff and students; it does not diagnose, it does not collect patient data and it asks users not to enter any.

Location is optional. It is requested only when the user taps a location action on the Mapa tab ("Usar mi ubicación" or nearest hospital). It is used on the device to compute straight-line distances and is never sent anywhere. If permission is denied the map, directory and schematic still work.

How to see offline mode: open the app once with a connection, then enable Airplane Mode and relaunch. Search (magnifier button), procedures, vademécum and códigos all keep working. Settings > Contenido shows the date of the data in use and that the server could not be reached; the last valid copy is kept. The Mapa tab caches the Madrid map tiles in the background the first time the map loads online; the hospital and base directory works offline either way.

Other features you may want to check: on iPad, Inicio, Códigos and Vademécum show list and detail side by side. The Apple Watch app (Códigos, Vademécum, Status 4) downloads the same public data from the backend, keeps the last copy for offline use, and can also receive it from the paired iPhone. Handoff publishes the open page so it can be continued in Safari on a Mac. Siri / Shortcuts: "Buscar en Manual SAMUR" opens search.
